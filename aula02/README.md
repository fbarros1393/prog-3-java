# Programação III — Aula 02

## Lista de Exercícios Práticos

Este diretório contém as atividades desenvolvidas na Aula 02 da disciplina de **Programação III**, ministrada pela professora Tainá Isabela.

Os exercícios foram implementados em Java e abordam conceitos fundamentais de Programação Orientada a Objetos, manipulação de Strings e utilização de coleções.

## Conteúdos trabalhados

- Classes, objetos, atributos e métodos.
- Instanciação de objetos.
- Atributos e métodos estáticos.
- Manipulação de Strings.
- Utilização de `ArrayList` e `Iterator`.
- Métodos para operações matemáticas.
- Validação e busca de informações.

## Exercícios desenvolvidos

### Exercício 01 — Classe Carro

Implementação de uma classe com os atributos marca, modelo e ano. Foram criados dois objetos para demonstrar a instanciação e a utilização de métodos.

**Arquivo:** `Exercicio01/Carro.java`

### Exercício 02 — Classe Contador

Implementação de um contador de objetos utilizando um atributo estático. A cada nova instância criada, o contador é incrementado.

**Arquivo:** `Exercicio02/Contador.java`

### Exercício 03 — Lista de Alunos

Utilização de `ArrayList<String>` para armazenar nomes de alunos e `Iterator` para percorrer a lista. Também foi implementada a remoção de um aluno.

**Arquivo:** `Exercicio03/TesteListaAlunos.java`

### Exercício 04 — Analisador de Texto

Programa para manipulação de Strings utilizando os métodos `trim()`, `length()`, `toUpperCase()`, `replace()` e `charAt()`.

**Arquivo:** `Exercicio04/AnalisadorTexto.java`

### Exercício 05 — Classe Produto

Implementação de uma classe com identificador, nome e preço. Foram criados métodos para aplicar descontos percentuais e exibir os detalhes dos produtos.

**Arquivo:** `Exercicio05/Produto.java`

### Exercício 06 — Sistema Bancário

Criação de uma classe para representar contas bancárias, utilizando `ArrayList` para armazenar contas e `Iterator` para percorrê-las e calcular o saldo total acumulado.

**Arquivo:** `Exercicio06/ContaBancaria.java`

### Exercício 07 — Cadastro de Pessoas

Implementação de um sistema simples para cadastrar e validar nomes de usuários.

O programa utiliza `ArrayList`, `Iterator`, `trim()`, `length()` e `equalsIgnoreCase()` para validação e busca de nomes.

**Arquivo:** `Exercicio07/CadastroPessoa.java`

## Tecnologias utilizadas

- Java
- Visual Studio Code
- JDK
- Git e GitHub

## Como executar

Para executar os programas, abra o terminal na pasta do exercício desejado.

Exemplo com o Exercício 01:

```bash
javac Carro.java
java Carro
```

No Exercício 05:

```bash
javac Produto.java
java TesteProduto
```

No Exercício 06:

```bash
javac ContaBancaria.java
java SistemaBanco
```

Os demais exercícios são executados utilizando o nome da classe que contém o método `main()`.

## Considerações finais

As atividades foram desenvolvidas para praticar os conceitos apresentados em aula, principalmente a criação de classes e objetos, a utilização de métodos e a manipulação de dados em coleções.

A resolução dos exercícios contribuiu para compreender melhor a estrutura de programas Java e a aplicação de conceitos de Programação Orientada a Objetos.
