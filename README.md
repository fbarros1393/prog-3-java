##  Como executar os códigos

Caso queira baixar este repositório e testar os códigos na sua máquina, certifique-se de ter o [Java JDK](https://www.oracle.com/java/technologies/downloads/) instalado (versão 17 ou superior).

1. Abra o terminal na pasta do arquivo desejado.
2. Compile o arquivo `.java` substituindo o nome abaixo pelo arquivo que deseja testar:
   ```bash
   javac <Nome_do_Arquivo>.java
   ```
3. Execute a classe gerada:
   ```bash
   java <Nome_do_Arquivo>
   ```
