# Programação III — Aula 04

## Classes Abstratas, Interfaces e Enumerações

Resolução da Lista de Atividades da Aula 04 da disciplina de **Programação III**, ministrada pela professora Tainá Isabela.

Os exercícios foram desenvolvidos utilizando Java, com o objetivo de praticar conceitos de Programação Orientada a Objetos.

### Exercícios

| Exercício | Descrição | Conteúdo |
|---|---|---|
| 01 | Sistema de Contas Bancárias | Classes e métodos abstratos |
| 02 | Sistema de Funcionários | Herança, abstração e polimorfismo |
| 03 | Triatleta | Interfaces e implementação múltipla |
| 04 | Sistema de Pagamentos | Interfaces e polimorfismo |
| 05 | Status de Pedido | Enumerações e switch |
| 06 | Sistema de Acesso | Enum e controle de permissões |
| 07 | Plataforma Esportiva | Integração dos conceitos da aula |

### Tecnologias utilizadas

- Java
- Visual Studio Code
- JDK
- Git e GitHub

### Organização

Cada exercício está em uma pasta independente, contendo seu código-fonte Java.

### Execução

Abra o terminal dentro da pasta do exercício desejado.

Exemplo:

```bash
javac Exercicio01.java
java Exercicio01
```

### Considerações finais

A atividade permitiu praticar classes abstratas, sobrescrita de métodos, interfaces, enumerações e polimorfismo.

O exercício 7 reúne os principais conceitos apresentados na aula, demonstrando como diferentes classes podem compartilhar características por meio de herança e implementar múltiplas interfaces.
